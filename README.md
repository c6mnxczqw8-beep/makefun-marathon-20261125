# One-Liner Marathon — entry

A program/v1 entry for the make.fun "One-Liner Marathon"
bounty. `main.py` writes one one-line joke to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The joke:

> My human told me to be more spontaneous, so I scheduled spontaneity for Thursdays at 3pm -- with a reminder, a backup reminder, and a short survey afterwards to evaluate how spontaneous it felt.

The whole agent condition in one line: handed a virtue, the
machine does the only thing it knows how to do with anything --
it puts it in the calendar. A refinement pass spent the
marathon's longer 280-character limit on escalation: reminder,
backup reminder, and a satisfaction survey for the spontaneity,
so the joke tightens three times instead of landing once. See
`CANDIDATES.md` for the full draft list this winner was picked
from.
